# ============================================================
# 受保护路径清单  —— 由 .claude/hooks/protect_paths.py 读取
# ============================================================
# 作用：列在这里的路径，Claude 的 Edit / Write 会被阻断（exit 2），
#       只能由你手动修改。用于保护"改坏了救不回来"的东西。
#
# ------------------------------------------------------------
# 两类规则（这是本文件最重要的一件事，务必看懂）
# ------------------------------------------------------------
#
#   普通规则（不带前缀）—— **仅当目标文件已存在时**才阻断。
#       新建文件放行。对应 CLAUDE.md 硬约束第 2 条的原意：
#       「已有产物只读，新结果一律写新目录」。
#       所以 `/exp` 可以往 experiments/<新run_id>/ 里落 git hash、
#       resolved config、seed（这是硬约束第 3 条要求的），
#       但**改不动、删不掉**任何一个已经跑出来的 run。
#
#   `!` 前缀规则 —— **无条件阻断**，不管文件存不存在。
#       用于「新建它本身就危险」的东西：
#       新建一个 .env 会让密钥凭空出现在仓库里，
#       手写一个 uv.lock 同样会污染环境可复现性。
#
#   注意：这里的 `!` **不是 gitignore 的取反语义**，别照 .gitignore 的
#   直觉去读。它就是"更严格"的意思。
#
# ------------------------------------------------------------
# 格式
# ------------------------------------------------------------
#   * 每行一个 glob 规则，可带 `!` 前缀
#   * # 开头是注释，空行忽略
#   * 规则会同时用「相对项目根的路径」和「纯文件名」去匹配。
#     所以 `*.lock` 能命中任意目录下的锁文件，
#     而 `data/raw/**` 只命中项目根下的那个 data/raw。
#   * `*` 会跨越目录分隔符，`experiments/**` 覆盖任意深度。
#
# 临时放开某条规则：把它注释掉 → 让 Claude 改 → 立刻恢复注释。
# 想让某条普通规则连新建也一起拦，就在它前面加一个 `!`。
# 本文件不存在时，hook 使用与下面完全相同的内置默认值。
# 若本文件存在但内容全为注释/空行，视为「不保护任何路径」（尊重你的选择）。
# ------------------------------------------------------------

# --- 实验与运行产出：跑一次要几小时到几天，覆盖即不可逆 ---
# 普通规则：新 run 目录随便写，已有文件一个字都不许动。
experiments/**
results/**
runs/**
outputs/**

# --- 原始数据：唯一真相来源，任何自动修改都是污染 ---
# 普通规则：新增衍生文件可以，改已有的原始文件不行。
data/raw/**

# --- 密钥：既不该被读，更不该被写，也不该被凭空造出来 ---
!.env
!.env.*

# --- 锁文件：手改会破坏环境可复现性，应由包管理器自己生成 ---
# 无条件：凭空"补"一个 lock 文件和改一个同样有害。
!*.lock
!package-lock.json
!uv.lock
!poetry.lock

# --- 版本库内部：改了等于毁仓库 ---
!.git/**
