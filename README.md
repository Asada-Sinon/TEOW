# TEOW

纯 JAX 实现的类星际 2D 网格 RTS 引擎:tick 制即时战略,采集 / 建造 / 升级 / 战斗
全链路,双方在 24×24 网格上从 4 个工人起家,摧毁对方大本营者胜。
路线:v1.x 打磨引擎(当前),v2+ 在其上训练强化学习指挥官(自研 PPO)。
引擎为 RL 预留了 controller 接口、动作合法性掩码与 vmap-able 的 `step`。

## 目录结构

```
src/teow/        引擎本体(config 数值真源 / state / step / economy / combat / movement ...)
src/run.py       入口:play 对局 / replay 回放 / serve 浏览器观战 / bench 基准
web/             浏览器观战前端(Canvas 矢量渲染,PNG 可替换槽)
tests/           pytest 用例
explorations/    一次性验证脚本(新想法先进这里,通过才进 src/)
experiments/     实验产物(一次 run 一个目录,只读)
docs/            plan / changelog / 决策记录
issue.md         需求唯一入口(按版本分节)
```

## 快速开始

```bash
# 全部测试
.venv/bin/pytest -q
# 跑一场脚本 AI 对局并录制(引擎单环境跑 CPU 更快,run 目录落 experiments/)
JAX_PLATFORMS=cpu .venv/bin/python src/run.py play --p0 scripted --p1 scripted --record --slug demo
# 浏览器观战刚才那局
.venv/bin/python src/run.py serve experiments/<run_id>   # → http://127.0.0.1:8000/
```

依赖用 [uv](https://docs.astral.sh/uv/) 管理:`uv sync` 建好 `.venv` 后按上面的
绝对路径调用解释器,不要用裸 `python`。

# 玩家手册

## 资源与采集名额

资源有两种:**矿石**(ore)与**水**(water)。地图共 8 个资源点——每家附近
1 矿 1 水,左下 / 右上双角各 1 矿 1 水为公共争夺点,整张图 180° 旋转对称、
严格公平。采集单位须先在资源点上建成**矿场**(矿点)或**泵站**(水点)才能
采集,一趟入账 = 载荷 + 矿泵等级加成,采满自动回大本营卸货再返程。
每个矿泵有**采集名额**:名额按矿泵等级 3→6 递增,**指派即占用**——运输
途中名额也不释放,满员的点不能再派人(重复对同一点下令除外)。

采集单位(v1.4)有三种,**均不能攻击、不能驻守、不能驻旗**,但都能建造:

| 采集单位 | 训练处 | 特点 |
|---|---|---|
| 工人 | 大本营 1 级 | 基础款 |
| 大力士工人 | 大本营 3 级 | 采得最快、载得更多,移速同工人 |
| 马车 | 大本营 5 级 | 载得最多、采速介于两者之间,移速同轻骑兵 |

## 护甲与伤害(v1.4)

伤害分**物理**与**魔法**两类:

- **护甲 = 物理减伤百分比**。实际物理伤害 = ⌈名义攻击 × (100 − 护甲) / 100⌉,
  至少 1 点。
- **魔法完全无视护甲**——法师是重甲单位(如重盔甲战士)的天敌,这是设计意图。
- 当前魔法来源:法师(v1.6 的法师塔 / 激光炮加入)。其余(弓箭/迫击炮/近战)
  均为物理。

## 科技树(以建筑为纲:几级爆什么)

> 各兵种详细数值见下方数值表;等级门槛看**生产建筑自身等级**。

### 大本营(HQ,1→7 级)

升级解锁高级建筑与单位、抬高全体等级上限,**不带任何单位属性加成**。

| 基地等级 | 解锁 |
|---|---|
| 1 级 | 训练:工人、近战步兵;建造:矿场、泵站 |
| 2 级 | 建造:技能训练营、兵营、哨塔(1 座) |
| 3 级 | 训练:大力士工人;建造:迫击炮(限 1 座) |
| 4 级 | 哨塔上限 → 2 座 |
| 5 级 | 训练:马车 |
| 6 级 | 哨塔上限 → 3 座 |
| 7 级 | (v1.6 内容的门槛预留) |

### 兵营(1→7 级,基地 2 级解锁,每家上限 2 座)

兵营自身可升级(上限 ≤ 基地等级),每级解锁新兵种:

| 兵营等级 | 可训练 | 定位 |
|---|---|---|
| 1 级 | 狗子 | 骑兵移速,战力低于近战步兵,骚扰/侦察 |
| 2 级 | 弓箭手 | 远程物理(射程 3.5),即时命中 |
| 3 级 | 轻骑兵 | 快速近战突击 |
| 3 级 | 重盔甲战士 | 中等血量 + 60% 高甲近战,物理很难啃动 |
| 4 级 | 法师 | 远程单体**魔法**(射程 3.0),无视护甲,克重甲 |
| 4 级 | 奶妈神官 | 不攻击;自动治疗射程内血量比例最低的友军单位 |
| 5 级 | 攻城车 | 近战,**只能攻击建筑**(对单位视而不见),拆家利器 |
| 6-7 级 | (v1.6:投石车 / 飞艇 / 龙骑兵) | — |

近战步兵在**大本营**训练(1 级即有),不占兵营位。

### 技能训练营(2→7 级,基地 2 级解锁,建成即 2 级)

**按兵种研发升级线**(v1.4 起八条线:步兵/狗/弓箭手/轻骑/重甲/法师/奶妈/
攻城车,各一条),每级提升该兵种血量与攻击(奶妈提升治疗量)。规则:

- 兵种解锁了(其生产建筑达到对应等级)才能研它的线;
- **线等级 ≤ 训练营等级 ≤ 基地等级**;
- 研发全局生效:场上存量与未来单位同享;营被拆,已购等级保留、在研中断不退款;
- 同一训练营同时只研一项;同线不可两营并研。

### 防御建筑

| 建筑 | 解锁 | 数量 | 行为 |
|---|---|---|---|
| 哨塔 | 基地 2 级 | 按基地等级 0/1/1/2/2/3/3 座 | 射程 4 自动攻击敌**单位**,可升级(血+攻) |
| 迫击炮 | 基地 3 级 | 每家 1 座 | 射程 2.5~7 环形(近处盲区打不了);**弹道制**:开火锁定目标当时位置,飞行 8 tick 后落点爆炸,范围 1.5 格、中心向外线性衰减——会走位就能躲;只打地面单位,间隔 40 tick |

## 单位与战斗

单位是连续 360° 移动的圆形体(建筑与资源点仍格子锚定),互相挤推、贴身可
挤过。近战射程 1.5 格(含对角),远程按各自射程即时命中;同 tick 同时结算
——互杀双亡是合法结局,同帧治疗也能救回将死单位。attack-move 以「自己
射程内出现自己打得动的目标」为停步条件:弓手法师在射程边停火输出,攻城车
无视拦路敌兵直扑建筑。每 tick 都可对任意单位下指令,no-op 永远合法。

## 驻守与军旗

**战斗单位**(八条线上的全部兵种)可**驻守**己方大本营、矿泵或军旗:走到
锚点 1.2 格圈内站住,被挤出圈自动回岗,永不自转闲置;驻守只站桩,不巡逻
不追击,但战斗照常。驻守目标被拆或易主时单位自动转闲置。**军旗**是自由
插点:拥有建成兵营后,战斗单位可在脚下自由格插旗(每家上限 3 面),此后
任意战斗单位可驻守该旗;撤旗由兵营下令、免费即时,原驻守单位原地转闲置。

## 胜负判定

摧毁敌方大本营即获胜;两个大本营同 tick 齐灭判和局;3000 tick 内未分
胜负判和局。终局后世界冻结。
