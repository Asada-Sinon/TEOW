# v1.8 — 多风格脚本指挥官 + 异界之门必分胜负(2026-07-27)

## 新增
- **异界之门 sudden-death(必分胜负,替代超时判和局)**:到 `gate_open_tick` 场地中央开门,
  **同时**向每个存活玩家出**阵营隔离**怪物(打玩家 p 的怪只打 p、也只有 p 能打它;跨阵营
  互不交互)。怪 **HP 无上限随 overtime 线性增**、**攻击力封顶**、**移速慢**、**近战**、
  **强度生成时定死**(后出更强、已在场不变),**各阵营压力一致**;某阵营死则其怪即时离场。
  效果:最弱基地先塌、最后存活者胜。独立 `src/teow/gate.py`(gate_tick 生成+慢速 descent /
  monster_combat_tick 阵营隔离近战,在 combat 与 cleanup 之间自成同帧子结算);`_end_tick`
  删和局、`episode_len` 保留为硬帽+残血打分兜底。(commit d39dfcf)
- **多风格脚本指挥官(v2 RL 对手池)**:`StrategyProfile` 参数化框架 + **10 风格**
  (balanced/boomer/rusher/turtle/timing/harasser/airtech/tempo/counter/chaos),纯 jnp
  branchless、可进 scan/vmap;profile 静态闭包→风格分支 trace 期解析。levers:经济旋钮
  (worker/attack/base_level/reserve)+ `tech_focus`(重排 build 链+预备金)+ `comp_bias`
  (兵种家族偏置;**counter=读敌方构成最佳响应**)+ `aggression`(defensive 延迟/allin 军空
  即突)+ `adaptive`(主力被清+过早期窗口→抬工人降激进转宏观,**反「无意义空转」**)+
  `stochastic`(chaos 用 key 加噪)。`make_controller` 分派 PROFILES 名;random/scripted 不变。
  (commit bb5feac)
- **批量吞吐基准 + 指挥官评测脚手架**:`explorations/bench_batch_v18.py`(GPU vmap 批量
  ~4000 env-tick/s)+ `explorations/eval_commanders_v18.py`(胜率矩阵+质量指标,v1.9 复用)。
  (commit 7c03a61 / bb5feac)
