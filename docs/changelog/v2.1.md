## 已知问题
- **真实训练吞吐 games/day**(含 gate+网+更新,bench_train_v21):B32T128 **62570**(甜点)/
  B64T128 53764/B128+ 降到 ~36k;gate 前后差异小(overtime 开销不大);B256T256 OOM(13GB)。分段
  rollout 显存可控(B64 3.4GB),训练非吞吐瓶颈。[source: 20260728-v21-throughput]
- **Phase D 小范围试训除险结论**:训练管线机器正确(slow test 4 passed + 数值稳定 + 吞吐已测),
  但**纯 PPO 从随机网冷启动学不动**——3 次训练(vsrandom/fix1/fix2)+ 全谱调参(β/pot_scale/
  stockpile/ent_coef)RL 始终探索不到结构化动作(造兵/采集),army=0、退化 NOOP/STOP/MOVE。根因是
  冷启动探索(随机网极少采样结构化动作 + 稀疏延迟奖励→无正样本),塑形强度救不了。**正式开训必须
  BC 暖启**(plan §1.4:脚本 oracle 蒸馏让策略从会造兵起步;用户 v2.1 暂缓 BC,留正式开训)
  [source: 20260728-v21-train-fix2]。这正是 issue.md v2.1「别训出什么都不会的指挥官」的除险价值:
  小范围试训阶段就发现了纯 PPO 会训废,避免正式开训才踩坑。
