# v1.1 — 升级系统与技能训练营(2026-07-25)

## 新增
- 等级体系:所有等级数值进 Config 查表(基地 1→7/矿泵/训练营/双升级线),
  state 加 `level[N]` 与 `upgrades[2,2]`(commit 01dc0f2)
- 建筑通用自升级 `A_UPGRADE`:扣费走槽号顺序对账 pass(同 tick 多笔不透支),
  升级与生产/研发互斥,矿泵升级不中断采集(commit c112554)
- 技能训练营:基地 2 级解锁、建成即 2 级;在建低血线性成长可被拆打断;
  步兵捆绑线+工人经济线研发,全局生效、存量单位补上限差额,拆营保留已购;
  上限链 线≤营≤基地 全部进合法性掩码(commit bd6c746)
- 脚本 AI 接入升级决策(升本→建营→轮研→升矿),metrics 加 base_level/upgrades
  (对局涌现「攀科技 vs 爆兵」权衡,两路线在不同 seed 各有胜局)
- 渲染:建筑等级角标、在建营半透明五边形、标题显示双方线级

## 修复
- **基地升级不再附带全军属性**(设计变更,保 rush/偷家博弈;详见 issue.md v1.1
  与用户决策)
- 同玩家同 tick 跨营对同一线并发研发会双倍扣费只得一级(审计 P0-1)→
  paid_orders_pass 扣费前按线去重只批槽号最小者;v1.1 控制器不触发但 v2 RL
  必踩(commit a980839)
- scripted 矿泵升级只查储备不查成本,掏空水库存曾助燃 seed12 活锁 →
  改查 成本+储备(commit a980839)
