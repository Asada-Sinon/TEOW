# explorations/

沙箱。新想法先在这里跑通，验证过了才升级进 `src/`。

规矩：

- **这里的代码可以脏**：写死路径、复制粘贴、没有测试、没有类型标注，都行。
  目的是尽快知道一个想法成不成立，不是留下资产。
- **这里的东西可以随时删**，不用问。删了就是删了。
- 一个想法一个子目录：`explorations/<YYYYMMDD>-<slug>/`。
- 输出写到 `explorations/<dir>/output/`，已被 gitignore，不会污染仓库。
- 升级进 `src/` 时是**重写**，不是移动：补测试、去掉写死路径、走统一 config。
  探索脚本本身留在原地当记录。

不要在这里放：任何别处会 import 的东西、任何需要长期正确的东西、
任何进 `research-log.md` 的正式实验（正式实验必须由 `src/` 下受版本控制的脚本产生）。
